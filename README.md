## 缩略图

- Named_Boxarts 文件夹里的图片统一尺寸为：600x745，图片来自：https://emumovies.com/files/file/5512-capcom-arcade-25d-custom-box-fronts

## 遮罩

overlays\cps2 文件夹里的遮罩文件命名规则：
- 以游戏 ROM 文件命名
- 一个游戏有多个遮罩的时候，以后缀 -a、-b、-c、-d 加以区分
